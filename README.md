This project analyzes billionaire data using Microsoft Excel (Pivot Tables & Slicers).
The dashboard focuses on total net worth distribution, age segmentation, gender, self-made status, and industry categories.

## 📊 Project Overview

The purpose of this analysis is to:

- Identify the total net worth distribution among selected billionaires
- Analyze age group distribution
- Compare self-made vs non self-made individuals
- Filter results by industry category
- Segment by gender

The dashboard is fully interactive using slicers.

## 🛠 Tools Used

- Microsoft Excel
- Pivot Tables
- Slicers
- Aggregations (SUM, COUNT)
